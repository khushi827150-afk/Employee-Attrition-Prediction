# IBM Employee Attrition Project

## Project Overview
This project uses Machine Learning to analyse employee attrition and identify patterns associated with employees leaving an organization.

## Objectives
- Analyse employee attrition patterns.
- Perform Exploratory Data Analysis (EDA).
- Apply data preprocessing techniques.
- Build and compare machine learning models.
- Evaluate model performance.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Machine Learning Models
- Random Forest

## Project Workflow
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Selection
5. Data Preprocessing
6. Model Training
7. Model Evaluation
